Lock schema

Every observed document is attested in vanguard.lock, a file committed to the repository like go.sum.

The lock records a human-attested baseline: the exact content hash, the anchor commit, and the hash of every watched scope tree — so the same repository state always produces the same verdict, offline. 

{
  "schema": 1,
  "docs": {
    "architecture-overview": {
      "observed_at": "2026-11-01T09:24:00Z",
      "content_hash": "sha256:9f2c…",
      "anchor": "a5181ca",
      "scope_tree_hash": "sha256:41bd…",
      "scope_file_count": 214,
      "watches": {
        "paths": ["docs/**"],
        "review_after": "2027-05-01"
      }
    }
  }
}
Design document GitHub

Where the signal comes from

Staleness is decided by hashing the declared scope — a scope tree hash over the document's paths watch — never by asking a model. Git history is used only for attribution: which exact commit churned a watched file, and which commit attested the last baseline.

Use the CLI

Two commands carry the whole contract. Structural errors are always fatal; per-document staleness composes into an exit bitmask that CI and agents consume without parsing prose.

Check — decide, never guess

$ vanguard check --format json
{
  "schema": 1,
  "documents": [{
    "id": "architecture-overview",
    "status": "stale",
    "reasons": ["scope_changed"],
    "introducing_commits": ["81243c6"]
  }]
}

Observe — attest, don't assume

$ vanguard observe architecture-overview
stale → fresh
anchor moved to 81243c6
scope: 214 files · sha256:41bd…

$ vanguard check
all documents fresh (exit 0)

Install & Run

Install vanguard

go install github.com/vanguard-lint/vanguard/cmd/vanguard@latest

Check a path scope

vanguard check --path 'docs/**'
vanguard check --path 'docs/api/**'

Check a commit range

vanguard check --from v1.2.0 --to HEAD
vanguard check --from v1.2.0 --fail-on-affected
